ytup

一个跑在个人计算机上的 YouTube 上传工具，通过官方 YouTube Data API v3 工作。

ytup 用于把本地渲染完成的视频发布到运营者自己的频道。它不提供在线服务、不接受第三方注册、不收集任何用户数据：所有处理都在本机完成，凭据也只保存在本机。

  • 使用官方 YouTube Data API v3，不依赖任何第三方中转服务
  • OAuth 2.0 授权，权限范围限定为 youtube.force-ssl
  • 无服务器、无数据库、无跟踪脚本

隐私权政策

Privacy Policy · 最后更新：2026 年 10 月 27 日

1. 适用范围

ytup（以下称「本应用」）是部署在运营者个人计算机上的本地命令行工具，用于通过 YouTube Data API v3 将运营者自己制作的视频上传到运营者本人的 YouTube 频道。

本应用不对外提供注册、登录或账号服务，不收集、不处理任何第三方用户的个人数据。使用本应用的用户即为运营者本人。

2. 使用的 Google API 服务

本应用使用 YouTube API Services。使用本应用即表示您同意受 YouTube 服务条款 约束。

本应用同时受 Google 隐私权政策 约束。

This application uses YouTube API Services. By using this application you agree to be bound by the YouTube Terms of Service. This application is also subject to the Google Privacy Policy.

3. 访问的数据

在获得频道所有者明确授权（OAuth 2.0）后，本应用仅访问以下数据：

  • 授权账号所属频道的频道 ID 与频道名称（用于核对是否授权到正确频道）；
  • 该频道自有视频的上传状态与处理状态；
  • 向该频道写入视频、封面、播放列表条目与字幕所需的最小权限。

本应用不读取其他用户的任何数据，不读取评论内容，不访问观看记录、订阅关系或任何非自有频道的数据。

4. 数据的存储与传输

  • OAuth 凭据（refresh_token / access_token）仅保存在运营者本机磁盘，路径为项目目录下的 profiles/ 与 state/。
  • 本应用不设立任何服务器，不将上述凭据或任何数据上传至运营者自建的云端或第三方存储。
  • 数据仅在运营者本机与 Google 官方 API 端点（googleapis.com）之间直接传输，全程使用 HTTPS。
  • 本应用不使用 Cookie，不使用任何第三方分析、广告或跟踪服务。

5. 数据的共享

本应用不出售、不出租、不交换、不向任何第三方披露任何数据。除向 Google 的 YouTube API 发送上传与查询请求这一必要行为外，不存在其他数据流向。

6. 数据保留与删除

运营者可随时通过以下任一方式撤销授权并删除数据：

  • 删除本机的 profiles/<profile>/token.json 文件；
  • 访问 Google 账号权限页，移除本应用的访问权限。

撤销后，本应用将立即失去访问该频道数据的能力。删除文件后，本机不再保留任何与授权相关的凭据。

7. 未成年人

本应用不面向未成年人，也不会有意收集未成年人的任何信息。

8. 政策变更

本政策如有变更，将更新本页顶部的「最后更新」日期。重大变更会在本页显著位置说明。
